## PRE-05

PRE-05 was registered before any archive object was validated. Its test as applied here: a class is a substantial conformance failure if and only if (a) the net error-class rate exceeds 5.0 percent of the objects in the stratum and (b) the collection-level median net rate also exceeds 5.0 percent. Both numbers are reported for both classes, including where the first fails. The net error-class rate is the union across validators: an object counts once if any validator raised a class adjudicated NET at Error severity.

| SOP class | net objects | objects | (a) net error rate pct | collections | (b) collection median net rate pct | (a) over 5.0 | (b) over 5.0 | verdict |

| Real World Value Mapping Storage | 0 | 20 | 0.0 | 1 | 0.0 | no | no | not a substantial conformance failure |
| Key Object Selection Document Storage | 40 | 40 | 100.0 | 1 | 100.0 | yes | yes | substantial conformance failure |

| SOP class | collection | net objects | objects | net rate pct |

| Key Object Selection Document Storage | qin_breast_dce_mri | 40 | 40 | 100.0 |

Each class sits in exactly one IDC collection, so the median across collections is that single collection's rate. The median is not a distribution here and should not be read as one.

PRE-05 words its threshold as a rate over series in a class, and the triples above are over objects. In these two classes the two denominators are the same: Real World Value Mapping Storage, 20 series and 20 objects; Key Object Selection Document Storage, 40 series and 40 objects. So the wording does not change the verdict.

Against the three bands PRE-05 fixed in advance, null at or below 5 percent and substantial above 20 percent with the band between reported as indeterminate: Real World Value Mapping Storage is null at 0.0 percent, and Key Object Selection Document Storage is substantial at 100.0 percent. For Key Object Selection Document Storage the prediction of a largely null result is wrong. Every object in the class omits a Type 2 attribute from a Mandatory module, and two independent validators say so.
